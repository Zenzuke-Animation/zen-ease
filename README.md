# zen-ease

A cubic Bezier easing editor extension for After Effects.

Documentation in English and Spanish: https://zenzuke.com/scripts/

## What it does

Zen Ease lets you adjust the easing handles of selected keyframes on a canvas built around cubic Bezier curves. When you apply a curve, the extension converts the handle positions into speed and influence coordinates and writes them directly to the keyframes in After Effects; you can also read the curve of existing keyframes back into the editor. It ships with easing presets, and offers shape, color, and curved spatial path estimation options.

## Requirements

- After Effects with scripting enabled.
- A ZXP installer, such as [Anastasiy's Extension Manager](https://www.anastasiy.com/extensions) or [ZXP Installer by aescripts + aeplugins](https://aescripts.com/awzxp-installer/).

## Install

1. Download `zen-ease_v1.2.3.zxp` from the [latest release](../../releases/latest).
2. Install the file with your ZXP installer (drag the `.zxp` onto it, or open it from the installer menu).
3. Restart After Effects if it was already open.
4. Open the extension from **Window > Extensions > Zen Ease**.
